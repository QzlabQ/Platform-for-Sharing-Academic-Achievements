# 数据源与同类平台调研记录

本记录保存公开入口、适用字段和课程中的使用边界。访问日期统一记为 2026-10-11；具体批量访问权限以各站最新条款为准。

| 编号 | 来源与公开入口 | 课程使用结论 | 复核状态 |
|---|---|---|---|
| D01 | [OpenAlex](https://openalex.org/) / [API文档](https://docs.openalex.org/) | 论文、作者、机构主数据候选；使用 work_id、DOI、作者、机构和主题字段 | 已记录入口；许可与限频需按最新文档复核 |
| D02 | [DBLP](https://dblp.org/) / [FAQ](https://dblp.org/faq/How+to+use+the+DBLP+data.html) | 计算机论文补充源；使用作者、题名、venue、年份和 DOI/URL | 已记录入口；遵守 FAQ 与 robots |
| D03 | [Crossref REST API](https://api.crossref.org/) | DOI 补全与交叉校验；使用 DOI、题名、作者、期刊、年份和许可证字段 | 已记录入口；按 API 规则限频 |
| D04 | [ORCID API文档](https://info.orcid.org/documentation/api-tutorials/) | 认领辅助验证与作者消歧；只读取公开记录 | 已记录入口；不单独自动通过认领 |
| D05 | [国家自然科学基金](https://www.nsfc.gov.cn/) | 少量项目公开字段人工导入或课程问卷数据 | 已记录官网；逐站核验公开字段 |
| D06 | [国家知识产权局](https://www.cnipa.gov.cn/) | 专利公开字段人工导入；不绕过验证码、登录或付费限制 | 已记录官网；逐站核验条款 |
| D07 | 学会、奖项官网公开名单 | 少量获奖公开信息人工导入 | 逐站记录来源和使用范围 |
| D08 | 高校、科研机构公开主页 | 机构和作者字段人工复核，最小化展示 | 尊重隐私、纠错和删除要求 |

## 同类平台对比维度

目标用户、内容类型、检索条件、个人门户、认领机制、数据来源、更新方式、统计分析、数据质量、隐私与申诉、对本项目启发。参照对象：中文学术数据库、Google Scholar、OpenAlex、DBLP、ORCID、ResearchGate/个人主页、高校科研门户。

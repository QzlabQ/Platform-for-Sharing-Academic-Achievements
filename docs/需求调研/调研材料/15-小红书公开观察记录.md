# 小红书公开观察记录

## 使用边界

- 仅浏览公开搜索结果和公开笔记，不发帖、不点赞、不评论、不关注、不上传文件。
- 这是“网络观察材料”，不是随机抽样调查，不能推断全体研究生或博士生的比例。
- 用途是补充需求主题、改进问卷字段和开发优先级。最终报告中必须与问卷数据分开标注。
- 搜索结果和互动数会变化，以下是 2026-10-11 在登录状态下观察到的结果，保存标题、主题和页面链接，不保存用户个人资料。

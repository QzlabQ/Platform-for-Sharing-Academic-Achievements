# 学术成果分享平台用户需求调研问卷

## 文件用途

- `学术成果分享平台用户需求调研问卷.txt`：用于问卷星“从文本创建问卷”。
- `学术成果分享平台用户需求调研问卷.jsonl`：用于后续调用问卷星 OpenAPI 的“从 JSON 创建问卷”接口。

## 问卷设计

问卷覆盖普通用户、科研人员和科研管理人员，重点收集：

- 当前学术成果检索与维护方式；
- 数据分散、重复、消歧、更新和准确性问题；
- 成果检索、个人门户、成果认领、纠错审核等核心功能需求；
- 合作网络、热点分析、推荐等创新功能的优先级；
- 数据来源、隐私、版权和成果归属方面的顾虑。

题型包含单选、多选、量表、矩阵量表、排序、单项填空和简答题。选项数量根据问题需要设置，不固定为四项。

## 导入后检查

1. 先导入文本版，检查分页栏、矩阵题和排序题是否被正确识别。
2. 将最后三道开放题设置为非必答；JSONL 版本已将其设置为 `requir=false`。
3. 检查“其他”选项是否需要开启文本补充框。
4. 检查多选题是否需要设置最多选择数量；本版暂未限制数量，便于先完整收集需求。
5. 发布前进行一次手机端预览，并用 1—2 份测试答卷验证统计结果。

## 与课程任务的对应关系

- 普通用户、科研人员、科研管理人员：支撑需求对象识别。
- 检索、认领、审核、数据治理和统计分析：支撑核心用例与 SRS 编写。
- 合作网络、热点分析和推荐：支撑创新功能选择。
- 数据准确性、来源、隐私和版权：支撑数据治理及合规需求分析。

# 访谈提纲与纪要模板

## 统一提纲

- 如何查找论文、专家、项目、专利或获奖信息？
- 如何维护成果清单？谁负责？
- 最近一次成果错误、重复、缺失或过期如何解决？
- 检索时最常用的筛选条件是什么？
- 门户最少展示哪些字段？哪些信息不应公开？
- 是否愿意认领门户？接受什么验证方式？
- 发现错误归属时，希望如何纠错、申诉和查看进度？
- 哪些统计结果真正用于工作？
- 如何看待来源、更新时间、隐私、版权与删除机制？
- 一期只能保留三个功能时，选择什么，为什么？

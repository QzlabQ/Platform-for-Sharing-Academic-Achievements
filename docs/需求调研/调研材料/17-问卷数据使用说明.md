# 116 份问卷使用说明

`12-问卷结果_116份.csv` 保存 116 份已回收答卷，每行对应一份答卷。

- 多选题采用分号分隔，便于拆分成长表。
- 量表题保留 1-5 数值，便于计算分布和交叉分析。
- 文件中的每一行均为本次分析纳入的有效答卷。
- 答卷来源和归档口径记录在版本材料中。
- 开放题内容保留为答卷中的主题句，访谈原话单独见 16-访谈记录稿.md。
- `13-问卷统计摘要.csv` 提供频数和比例。
- `14-问卷字段说明.csv` 提供字段含义和分析映射。
- `18-问卷长表_多选拆分_116份.csv` 将多选题和排序题拆成一行一项，适合可视化与接口导入。

# 领域分类与合规评估

## 分类方案

采用“一级学科大类 + 二级标签 + 多领域关联”。一项成果保存一个主领域和零个或多个辅助领域；自动分类只给候选；低置信度或冲突结果进入人工复核队列；记录来源、置信度和复核人。

## 合规底线

- 不爬收费数据库，不保存受保护全文。
- 不绕过登录、验证码、付费墙或其他技术措施。
- 优先官方 API、开放数据集和课程问卷数据。
- 保存来源、更新时间、处理状态和审核记录。
- 只展示完成业务所需的公开信息，联系方式默认隐藏。
- 为科研人员提供认领、纠错、申诉和隐藏机制。
- “网页可访问”不等于“允许批量抓取”，逐站核验条款和 robots。

# ScholarFlow UI 原型

## 打开方式

使用 Chrome 或 Edge 直接打开 `index.html`。原型不依赖网络、npm、后端服务或数据库，可离线浏览。

## 页面导航

点击页面右下角的“原型页面”按钮，可切换以下六类页面：

1. 成果检索页
2. 学者门户页
3. 成果详情页
4. 认领申请页
5. 采集任务管理页
6. 认领审核页

“关键场景”区域提供两个演示入口：

- 检索过滤与分页：载入“大模型”查询，可继续勾选类型、年份并切换分页。
- 认领提交与审核反馈：重置认领状态后进入三步申请流程。
- 重置原型状态：恢复认领、任务和筛选的初始演示数据。

## 可演示交互

- 检索：关键词、类型、年份、领域和机构过滤；排序；分页；活动筛选标签；空结果。
- 门户：学者标签页切换；未认领与已认领状态；从成果详情进入认领。
- 认领：保存草稿；ORCID 与申请说明校验；三步提交；申请编号与审核时间线。
- 审核：管理员通过/驳回；通过前核验确认；驳回原因；审核结果在申请页回显。
- 采集任务：新建任务；任务详情抽屉；停止运行中任务；失败任务重试；状态筛选与分页。

## 文件说明

- `index.html`：原型入口和页面导航。
- `assets/styles.css`：颜色令牌、布局和组件样式。
- `assets/app.js`：页面路由、示例数据和交互逻辑。

原型中的学者、成果、认领申请和采集任务均为演示数据，不代表真实个人或已经上线的业务记录。
